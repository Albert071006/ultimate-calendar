# 正式资料与生活助手归常在线资料服务，采集电脑只发送提炼结果

状态：已接受；2026-10-24。此 ADR 记录架构方向，当前交付范围是源码与本机合成资料验证，不代表已部署、迁移现有个人资料或发布新安装包。

手机有网络、Windows 采集电脑关机时，日历、账本、生活助手及到时提醒仍需可用。因此正式资料与业务写入交给常在线资料服务，桌面网页和手机网页共用同一接口；AI 密钥留在该服务。主机在本决策中只指运行 QQ 自动采集的 Windows 电脑，保留 QQ 原文及附件，只发送提炼结果。平台无关资料接口继续与 Windows 文件、更新、凭据和采集能力分离。

把 Windows 电脑作为唯一权威资料来源可以减少托管，但无法满足电脑关机后的手机读写和提醒；在每台设备各存一份权威资料则引入双向合并、重复记账和密钥散布。因此采用单个资料服务，并接受其持续运行、访问保护、托管费用、私有备份和受控迁移成本。Tailscale 可保护服务入口，不能把 Windows 电脑重新变成必经中转。

## 持久提交与恢复

客户端离线暂存不成为第二份权威资料。请求标识、资料实例和恢复代际与业务版本一起核对；主机已保存但响应丢失时查询原回执，不生成新请求盲重放。现有日程／账本持久去重继续复用；网络回执独立保存，重启后未确认完成的请求停止自动执行，尤其不自动重新调用收费模型。牺牲部分未知请求的自动恢复，换取不把“可能已经执行”当作“确定没执行”。预览仍由业务服务生成，确认时重新检查，不能将过期离线预览直接执行。

## 资料与隐私

QQ 上传只接受严格提炼字段白名单和稳定提炼编号，云端建立占位来源；原句、截图、附件、群／账号标识、路径和采集引用不属于该契约。手机主动提交的消息原文为短期分析输入，成功后清理，失败输入设有限保留期；正式候选、任务和账目继续保留。

服务不复用含输入原文的桌面整库自动备份，而导出保留正式资料及完整账本的脱敏 JSON。回执、设备会话、推送密钥及 AI 密钥分开保管。恢复只允许全新或空目录，严格校验后在同级暂存并回读核对，成功才移动到目标；新资料实例隔离旧队列，重新配对和配置密钥。代价是不能直接覆盖已有库或沿用设备授权；Windows 既有资料迁移仍须单独实现。资料服务采用独占目录和显式配置，不自动猜测 Windows 数据目录。

## 交付边界

当前 Node HTTP 服务与同源网页可本机运行；原生 Electron 桌面仍使用原本的本地资料模式，远程桥、现有资料迁移和实际云资源部署需显式完成后，才能声称全部桌面与手机都使用同一份正式资料。远程桥不得通过放宽 Cookie、Host 或 Origin 校验实现。手机推送的浏览器权限、锁屏送达及真实设备体验仍需真机验收。
