# 手机端有自己的外壳与页面布局，只与桌面共享业务层

状态：已接受；2026-10-25。

手机首版曾直接渲染桌面 `App`，再用 `.is-mobile` 样式覆盖、`:has()` 隐藏导航和 `pointer-events` 屏蔽来挤进窄屏。结果像桌面缩小版，桌面改版也会连带弄坏手机。因此手机端在 `src/renderer/mobile/` 下自建外壳（顶栏、底部标签、底部面板、全屏编辑）和五页布局；领域规则、`PlannerClient`、离线队列、预览确认与撤销、表单校验等业务层继续两端共用，桌面版面组件不再承担手机分支。

代价是两套页面布局要分别维护，新增业务入口时两端都要摆放。不要为了“少写代码”把手机页面改回“复用桌面组件 + 手机样式覆盖”；需要共享的是 hook、纯函数和字段级组件，不是页面版面。
