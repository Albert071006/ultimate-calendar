# 专注记录独立保存，运行中的计时器由发起设备负责

状态：已接受；2026-11-29。

执行时段（`Block` 的 `work` 类型）表示打算何时做事，专注记录（`FocusSession`）记录实际投入。两者可以通过 `blockId` 关联，一个计划时段可以对应多轮番茄，自由计时和手动补录也可以没有计划。统计按记录中的有效秒数累计，暂停和休息不算投入。代价是多维护一种同步实体，也需要在删除任务、时段、课程或目标时解除关联并保留历史。复用执行时段虽然少一套存储，却会让每轮番茄和休息切碎计划，也使课程和目标统计难以区分预计时长与实际投入。

倒计时与正向计时由发起设备按真实墙钟时间戳计算。运行状态、当前一段的起点和已累计的有效时间写入该设备的 `localStorage`，刷新、锁屏或重启后据此恢复。远程端按资料实例和恢复代际区分本地状态，避免切换资料后将旧计时结算到新库。结算后的记录写入共享资料库，通过现有增量同步送到其他设备，并随正式资料备份和恢复。

跨设备续接实时秒表需要协调暂停、恢复、设备时钟漂移和离线冲突。采用本地计时的代价是运行中的计时只能在原设备继续，清除本地存储也会丢失未结算的计时。
