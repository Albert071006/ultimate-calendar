# 终极日历本地版

本地版是面向 Windows x64 的独立桌面应用。日历、任务、课表、目标和账本都在自己的电脑上处理、保存，无需部署日历服务器。AI 由本机直接调用 DeepSeek；本地版没有手机端、设备配对或跨设备同步。

## 下载与首次使用

在[本地版 0.5.0 Release](https://github.com/Albert071006/ultimate-calendar/releases/tag/v0.5.0) 下载 `UltimateCalendar-Local-Setup-0.5.0.exe`。安装后从「终极日历本地版」快捷方式启动。安装包已包含运行环境，无需 Node.js。服务器版另有独立 Release，不是使用本地版的前置条件。

首次打开即可手动创建日程、任务、课表及账目，不需要注册日历账号、填写服务器地址或配置 API Key。新资料没有预置私人课表、账单或群名单；周期收入默认关闭，需要时自行设置。

安装包目前未购买代码签名证书。请从本仓库正式 Release 下载，并按同一版本的 `SHA256SUMS-local.txt` 核对文件。不要从不明来源获取修改过的安装包。

## 配置 AI

在「我的 → AI 与费用」展开 API Key，保存自己的 DeepSeek API Key，再选择账户可用的模型。已保存的有效 Key 会在重启和更新后继续读取，无需每次填写。

本机直接访问 DeepSeek API，不经过作者提供的日历服务器。当前仅接入 DeepSeek，暂不支持任意自定义 API 地址。账户模型、余额与价格查询也需要联网；模型请求产生的费用由自己的 DeepSeek 账户承担。

使用生活助手、消息提炼、图片或附件分析时，完成请求所需的输入及相关上下文会发给 DeepSeek。普通日历和账本的手动读写、查看已有资料、计划文件导入、本机备份恢复不调用 AI。

生活助手可添加或粘贴一张 PNG/JPEG 图片，单张不超过 10 MiB。图片和扫描件的分析取决于所选模型是否支持视觉输入；应用没有本地 OCR。助手使用最近 20 条已完成对话作为上下文；重启后聊天显示清空，已经保存的日程和账目仍保留。

## 桌面功能

| 功能 | 使用方式 |
| --- | --- |
| 日历、课表、任务与目标 | 本机保存；支持教学周、重复活动、截止时间和执行时段。时段完成与整项任务完成分别记录。 |
| 账本 | 本机保存收支、AA、代垫、退款、报销、转账、余额核对及更正记录；支持 CSV 导出。 |
| 生活助手 | 本机直接调用 DeepSeek，涉及核对的修改先展示预览。 |
| 通知与附件提炼 | 手动导入或可选 QQ 采集；AI 提炼后进入待判断列表，由用户决定是否采用。 |
| 网页与电脑资料 | 关联网页、文件和文件夹；关联原文件需仍位于可访问的位置。 |
| 外部 Agent 计划 | 导入 v1 新计划、v2 追加计划、v3 修订计划；导入前核对，不再调用 AI 解析。 |
| 提醒 | 使用 Windows 通知；需日历进程运行，关机、休眠或退出期间不能即时提醒。 |
| 备份、恢复与空间管理 | 在「我的 → 数据与备份」管理本机资料。 |

账本目前提供六类预设账户，不包含完整的信用卡负债管理。日程与账目按北京时间处理。

## 可选的 QQ 采集与附件解析

QQ 自动采集需要自行准备在本机运行的 OneBot 兼容桥接组件。安装包不包含 QQ 客户端或桥接组件，也不替用户登录 QQ。采集默认关闭；在「QQ 采集」填写本机桥接地址和访问令牌，连接后选择需要采集的群。

这个可选桥接进程只负责连接本机 QQ，不是日历资料服务器。未配置桥接时，日历、账本、生活助手和手动消息导入仍可使用。自动采集兼容性取决于 QQ 和桥接组件版本；微信采集尚未提供，语音和视频不做内容分析。

附件支持 PDF、Word、Excel、PPT 和纯文本。旧版 DOC/PPT 需要额外安装 LibreOffice，可通过 `PLANNER_LIBREOFFICE_DIR` 指定其根目录或 `program` 目录。扫描件和图片依赖所选模型的视觉能力。详见[附件解析说明](../src/capture/documents/README.md)。

## 数据、备份与升级

默认使用系统的「文档」目录，具体位置跟随 Windows 的文档目录设置：

| 内容 | 本地版默认位置 |
| --- | --- |
| 数据库、设置、附件与加密凭据 | `文档/终极日历本地版/数据` |
| 自动备份 | `文档/终极日历本地版/备份` |

API Key 和桥接令牌由 Electron 的系统加密存储保护。系统加密不可用时，界面会说明密钥仅在本次运行有效；不要把密钥放进源码、截图、反馈或共享备份中。

本机备份包含日历、账本、操作记录及仍保留的 QQ 原文和附件，不包含 API Key，也不会复制关联的外部原文件。备份同样包含私人资料，须妥善保存。自动清理保留正式记录、被进行中事项引用的附件及必要的最新有效备份，具体见[空间管理规则](storage-management.md)。

本地版使用独立的安装身份、数据目录及 `local` 更新通道。它不会读取标准版的默认云端连接文件，不会自动迁移标准版或云端资料，也不会与它们自动合并。需要迁移时，先在原版本导出并确认备份格式和内容，不要把运行中的 SQLite 文件直接复制覆盖。

更新只更新本地版程序，保留本地版资料和凭据。更新前应用会检查是否有正在处理的操作并准备备份；无需重新填写正常保存的 Key。应用内更新和 GitHub 下载需要联网，但日历服务器不参与。

## 从源码构建

```powershell
npm ci
npm run typecheck
npm test
npm run build:local
npm run package:local
```

需要 Windows 和 Node.js 24 或更新版本。安装包生成在 `release-local/`，包括本地版 `.exe`、`.exe.blockmap`、`local.yml` 和 `SHA256SUMS-local.txt`。打包不会发布，也不会访问个人资料或调用收费 AI。

开发时使用独立测试资料：

```powershell
npm run dev:local -- --planner-profile="$env:TEMP\ultimate-calendar-dev"
```

测试请使用虚构日历、账目和模拟桥接，勿填写真实密钥。需要手机与电脑共用资料时，另见[服务器版与手机端 Release](https://github.com/Albert071006/ultimate-calendar/releases/tag/server-v0.5.0)及[Linux 部署指南](server-mobile-deployment.md)。
