## 终极日历本地版 0.10.0

下载 `UltimateCalendar-Local-Setup-0.10.0.exe`，适用于 Windows x64。日历、课表、任务和账本保存在自己的电脑上，无需部署服务器；AI 由本机调用自己的 DeepSeek API。本地版只有桌面端，没有手机端或跨设备同步。

### 操作与备份

接受事项、完成任务和保存设置先完成数据库事务，再更新受影响的界面。包含采集原文的本机完整自动备份继续每天生成一次，改由后台执行，普通操作不再等待整库备份和旧备份扫描。“我的 → 数据与备份”显示等待、运行、失败及最近成功状态；正常退出会等待备份收尾，恢复和更新前的保护备份保留。

### 减少 AI 重复输入

- 生活助手的记账分流使用精简上下文，减少无关日历资料；稳定规则前置，便于服务商复用相同请求前缀。
- 日历引用与群通知采用紧凑表示，重复正文只携带一次。记账保留最新账目索引及相关详情；修改旧账或处理退款、AA 等关联时，先补齐所需原记录，再核对和保存。
- 采集分析可按来源补读必要证据，附件提取结果按内容及解析版本复用。无法读取、内容变化或证据不完整时保留待核对，不推测缺失内容，也不为升级重跑已完成的分析。

实际输入量和缓存命中率取决于消息内容、补读次数及服务商缓存状态；本次不承诺固定节省比例。去重、来源验证、原操作回执及结果未知保护继续保留。

### 采集修复

微信附件更清楚地区分仅有缩略图、尚未下载和密钥不可用等状态。通知中只有日期、没有时分的活动保留暂定信息，不补造具体时间；已保存回答可在核对后继续处理。

### 升级

保存草稿并正常退出后安装，保留已有资料、API Key 和群选择。继续使用独立安装身份、资料目录及 `local.yml` 更新通道；用同一 Release 的 `SHA256SUMS-local.txt` 核对安装包。安装包未购买代码签名证书。

本版新增增量同步记录及采集分析检查点字段。回退前需核对旧程序能否读取新检查点和操作回执，不要通过清空资料或恢复旧数据库完成普通程序降级。手动“记一笔”仍保持纯手动，升级不会补账或重分类已有流水。

需要电脑和手机共用资料时，使用单独发布的[服务器版与手机端 0.10.0](https://github.com/Albert071006/ultimate-calendar/releases/tag/server-v0.10.0)，并自行部署常在线服务器。
