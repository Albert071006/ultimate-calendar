# 终极日历本地版 0.10.1

本版修复账本查询、连续追问、报销及手动分类选择，继续使用独立的本地资料目录和更新通道。

- 活动或用途查询区分单笔项目、备注与整批记账原文，避免同批无关消费被一起统计；支持限定搜索字段或明确账目，结果显示筛选范围与笔数。
- 查询澄清选项保留明确范围，回答“第一个”等短答直接执行对应只读查询。多轮补充保留原需求和已提供信息，避免因只看最近一句而丢掉账户依据；失败或结果未知的请求不自动混入下一次操作。
- 明确全额报销多笔消费时，按各笔尚未冲减的金额处理，支持不同分类及月份。实际到账只记一次，用户明确的超额收入单独计入收入；部分分配不明时正常追问，整批未保存，不以重新分析代替补充信息。
- “记一笔”的分类箭头可直接展开已有和建议分类，同时支持自定义输入；保持纯手动分类。
- 微信启动期间账号或身份暂不可用时保留原绑定、群选择和采集开关并重试；明确检测到账号改变时仍停止采集，身份不明时不读取其他账号。

保存草稿并正常退出后安装，保留资料与有效密钥。升级不补记历史失败账目、不重跑已完成分析、不批量改分类。新的查询范围和选项可能保存在操作回执中，降级前需核对旧程序能否读取；不要恢复旧数据库来回退程序。

安装包及 `local.yml`、校验表来自同次构建。需要电脑与手机共用资料，请使用单独发布的[服务器版与手机端 0.10.1](https://github.com/Albert071006/ultimate-calendar/releases/tag/server-v0.10.1)。
