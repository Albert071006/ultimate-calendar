# 终极日历本地版 0.10.2

本版集中修复群通知识别、活动时间、冲突预览，以及日历、生活助手和账单的日常使用问题。

- 群通知支持读取腾讯文档和小程序卡片的可见标题、简介与网页链接，不自动访问链接正文；后续报名资格、剩余名额等补充可联系原通知。限定人群但本人资格未知时，提示保留待判断和适用条件。
- 时间识别兼容“晚上 7 点”“周三晚7点”等写法。引用只有日期时可核对同一句原文的钟点；同一活动“14:30 到 16:00”的结束时间可沿用已核对的开始日期，接受后和导出忙碌时间时保留完整时长。日期已知而钟点不明时明确提示核对。
- 课程本身的考核不再被误报为与这节课冲突，真实时间重叠仍提示。冲突弹窗显示另一项已有安排，接受通知的预览优先显示将加入日历的内容，具体变更可展开查看。
- 日历窄列更充分显示活动名称，工具栏不会因提示或翻周突然下移；固定活动结束后显示“已结束”，不自动标记完成，需要完成的执行时段仍提示待处理。截止条、单日提示和计划导入列表的时间显示更清楚。
- 生活助手去除重复的保存提示，支持常用 Markdown 和中文日期；相关日程默认折叠，长回复从开头显示。电脑收起面板期间收到回复，再展开也能看到回答开头。
- 账单统一显示全部月份的代垫与借出本金待收回合计，借款明细补充原金额及剩余金额；未设置余额时说明状态，记账汇总使用中文月份并省略无关的零值项目。外部 AI 导出说明更简洁，详细说明可展开。

升级保留资料与有效密钥，不自动重跑历史分析或改变通知的接受、忽略选择。能从已保存原文核对的旧待判断时间可恢复显示；已接受活动或人工修改过的结束时间不会批量重写。识别仍以原文依据为准，不把适用资格未知当作已满足。

本地版和服务器版继续使用独立安装身份、资料目录及更新通道。保存草稿、正常退出后安装。电脑与手机共用资料请使用[服务器版与手机端 0.10.2](https://github.com/Albert071006/ultimate-calendar/releases/tag/server-v0.10.2)。
