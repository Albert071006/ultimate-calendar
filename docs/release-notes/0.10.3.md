# 终极日历本地版 0.10.3

本版完成全项目系统性审计修复，重点加固导入与原文清理的隐私边界、账本与生活助手准确性、QQ/微信采集可靠性，以及长列表与账本操作日志性能。

- 截图导入仅提交当前标签可见内容，不再把先前切走的文字草稿一并保存或发给 AI；清理本机采集原文时会同步擦除日历来源和回执里的正文副本，本机来源查看器明确展示已清理状态。
- 账本与生活助手防错升级：手工编辑账目分开管理多账户分摊、返款关联与冲减对象，仅改备注不再破坏已有分摊或待收款；AI 记账在保存前核对原话金额、更正原笔金额及用户明确指认的付款账户，禁止模型自行跳过重复账确认；拆清图片追问的只读问答与按历史收据记账。
- QQ 与微信采集更稳更准：群内追加的独立新作业不再被合并进已忽略旧卡；微信缺件自动重试限为消息发送后 3 天内；QQ 未就绪附件警告按来源归属隔离，不再连累同批正常纯文字通知；微信拆开最新消息与 7 天窗口巡检游标补抓延迟同步消息，完整扫描 100 人以上超长 @ 名单，并在读取子进程超时退出后由父进程补清临时目录；补充 Windows QQ 采集 LLBot 安装指南。
- 离线恢复兼容课程/目标颜色为空的合法旧备份；收件箱建立来源索引并分页显示，微信重复纯文字消息直接短路跳过多余附件查询；账本新写入改用向后兼容的可逆差量记录，大幅缩小操作日志体积，旧历史记录照常可撤销。

升级保留既有资料与有效密钥，不自动重跑历史分析或改写已处理通知。新版写入的差量账本日志与新采集检查点需由支持它们的版本读取，回退旧程序前请先核对兼容性。

本地版和服务器版继续使用独立安装身份、资料目录及更新通道。保存草稿、正常退出后安装。电脑与手机共用资料请使用[服务器版与手机端 0.10.3](https://github.com/Albert071006/ultimate-calendar/releases/tag/server-v0.10.3)。
