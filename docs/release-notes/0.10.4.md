# 终极日历本地版 0.10.4

本版简化了账单更正，在桌面各页统一了操作提示，并支持用鼠标滚轮翻日历。

- 手工更正账单时免填「更正说明」，可直接保存。打开账单详情的「修改记录」即可查看哪些字段发生了变化，例如「金额 2.60 → 3.00」。只改备注时记为「修改备注」，原样保存时记为「手工核对保存」。作废说明选填，留空记为「手工移除」。生活助手提交的修改理由照常保存在记录中。
- 日历、今天、待判断、账单和设置的操作提示统一显示在底部生活助手上方，展开对话时自动避让。提示约 4 秒后淡出，鼠标悬停或键盘焦点停在「撤销」按钮上时暂停计时。日程和账单各自撤销对应操作，提示消失后仍可用顶栏撤销。错误提示会保留至关闭或问题解决。
- 在日历工具栏或日期表头向下滚动可翻到下一天、下一周或下个月，向上滚动可返回。日历主体支持 Shift＋滚轮和横向滑动。日、周时间轴可照常上下滚动。月视图一屏可见时可直接滚轮翻月，窗口较矮时优先滚动内容。连续滚动产生的惯性会被过滤，避免一次滑过多页。
- 桌面记住上次选用的日、周或月视图。从月视图点开某天也会记住日视图。切换侧栏页面后再回日历，或下次启动时，都能继续使用该视图。重新启动时日期仍为今天。

本地版继续使用独立的安装身份、资料目录和更新通道。请保存草稿，正常退出后安装。电脑与手机共用资料请使用[服务器版与手机端 0.10.4](https://github.com/Albert071006/ultimate-calendar/releases/tag/server-v0.10.4)。
