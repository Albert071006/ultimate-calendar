# 终极日历本地版 0.10.5

本版可以用番茄钟或正向计时记录实际工作时间，再到「时间账单」查看各门课程和目标上的投入。专注记录与计划时段分别保存，同一时段可以做几轮番茄，也可以直接开始自由计时。

- 在桌面侧栏点「专注」，或从「今天」的任务和日历中的执行时段开始计时。切换页面后，迷你计时条仍可暂停、继续或结束本轮。
- 计时器按实际经过时间续计。暂停时间会扣除，重新打开应用后可以接着计时。番茄在关闭期间到点，再次打开时会按原目标时长等待保存。有效专注满 1 分钟即可保存，休息由你选择开始。
- 「今日专注」显示当天时长和完成番茄数。在「我的 → 专注统计」切换日、周、月，可看每日柱状图、课程和目标的投入占比，以及按天分组的明细。支持手动补录、编辑、删除和撤销。专注默认 25 分钟，短休 5 分钟，每 4 轮可长休 15 分钟，时长、间隔和提示音均可在「番茄钟与专注」中调整。
- 可以问生活助手「这周高数花了多少小时」，也可补记刚结束的一次专注。修改或删除历史记录先预览确认，指代不清时会追问。助手可启停本机计时，遇到已有计时会请你选择如何切换，重试同一请求也不会重复启动。
- 日历打开时即绑定滚轮翻页，刚进入页面的首次滚动也能响应。

请保存草稿，正常退出后安装。升级会在原有本机数据库中自动创建专注记录表并补入默认设置。旧备份仍可恢复，没有专注记录的备份恢复后显示空的专注历史。需要电脑与手机共用记录时，请使用[服务器版与手机端 0.10.5](https://github.com/Albert071006/ultimate-calendar/releases/tag/server-v0.10.5)。
