## 结束后待处理

- 未完成的任务超过 DDL、活动或执行时段结束后继续留在任务页和日历右侧，显示橙色待处理提示。
- 逾期任务可以直接修改 DDL；已结束安排可以调整原时段、标记完成或移除。调整执行时间不会改动任务的截止日期。
- 日历中的未完成个人活动结束后变为浅橙色，完成后保留淡色历史；普通课程的显示不受影响。

## 已安排任务

- 修复任务已有执行时段时仍显示“安排”的问题，统一显示已有固定活动和执行时段。
- “查看安排”打开已保存的时段，保存修改不会新增重复记录；详情可以查看并调整每一项安排。

时间经过只改变提示，不自动完成、删除或修改已有记录。此前已经接受的过期任务会重新出现在待办中，方便逐项处理。未接受的过期通知仍留在“已过期”中。
