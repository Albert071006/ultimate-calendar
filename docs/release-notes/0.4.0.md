## 全新界面：纸本 · 套色

- 导航精简为五项：今天、日历、待判断、账单、我的。界面改为纸本风格，新增衬线标题字体（思源宋体子集，SIL OFL 1.1）。
- 点击日程弹出详情卡片，可直接完成、删除或编辑，操作都能撤销；双击日程直接打开右侧编辑面板。
- 日视图右侧显示当天截止和待决定的通知；月视图把课程收成日期旁的小圆点，每天最多列 3 项，点日期进入当天。
- “未安排”抽屉只列出逾期、尚未安排或安排已结束的任务，拖到日历上即可安排。

## 课程与目标的颜色

- 课程和目标有了自己的颜色，日历、待办和详情都按归属上色。升级后会自动为已有课程和目标分配颜色，同名课程颜色一致。
- 在“我的 › 课程表 / 目标”用 16 色调色板改色，已被占用的颜色会标出。只改颜色不再弹出确认预览，可撤销。
- 任务可以关联课程，关联后执行时段使用这门课的颜色。

## 待判断与账单

- 待判断改为左侧列表、右侧详情。每条通知都可直接接受或忽略，底部可撤销；支持键盘：上下切换，A 接受，I 忽略，L 稍后。
- 详情标明收益是“原文写明”还是“AI 推测”，并高亮原文中的时间。
- 账单分为“收支”和“账户”两页；“收支”新增“待收回”，即代垫金额减去已关联的收回款。记账规则移到“我的 › 记账”。
- 设置移到“我的”，每次只显示一个分区；保存时仍会一并保存其他分区的设置。

## 可读性

- 文字对比度达到 WCAG AA；短日程块不再把时间、地点或状态切掉一半。

## 升级与回退

- 安装更新前会自动备份本机资料；升级保留课程、任务、日程、账本、QQ 采集记录和 API Key，无需重新填写。
- 新版本会写入课程和目标的颜色等新字段。升级后如需回退到 0.3.x，请先恢复升级前的备份，不要直接用 0.3.x 打开新版本的数据。
