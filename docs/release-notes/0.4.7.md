## 资料目录与空间管理

- 修复从不同 Windows 启动环境打开应用时可能读取另一份 AppData 数据库，导致界面看起来资料丢失的问题。正式资料统一存放在系统“文档/终极日历/数据”，已有旧库通过兼容迁移保留。
- 默认备份统一放在“文档/终极日历/备份”。迁移保留加密凭据和配置；发现不同的有效源库或无法可靠读取时停止并提示，避免覆盖资料。
- “我的 → 数据与备份”新增空间管理：显示占用、预览清理，并配置备份数量、容量和已处理 QQ 附件的保留期限。
- 默认保留自动备份 7 份、安全备份 3 份，备份容量目标 2048 MiB；已处理附件默认保留 30 天、容量目标 1024 MiB。
- 清理保留账单、任务、课表、目标、消息正文、提炼结果和操作历史；仍被进行中事项引用的附件与必要的最新有效备份优先保留。手动导出及未知文件不自动删除。
- 备份／恢复不再限制整体文件为 512 MiB，逐条校验和复制附件，并检查磁盘可用空间。恢复保持事务与安全备份保护。

本版不提供手机端或跨设备连接功能。旧目录原库保留，不能在应用运行期间手动替换数据库文件。详细规则见 [空间管理说明](https://github.com/Albert071006/ultimate-calendar/blob/main/docs/storage-management.md)。
