## 独立本地桌面版

- 新增「终极日历本地版」Windows x64 安装包：`UltimateCalendar-Local-Setup-0.5.0.exe`。无需部署日历服务器、注册日历账号或配对设备，安装后可直接手动管理日历、课表、任务、目标与账本。
- AI 由本机直接调用用户自己的 DeepSeek API Key。未配置 Key 时，本机手动功能仍可使用；使用 AI 需要联网并由用户的 API 账户承担费用。
- 本地版仅提供桌面端，不包含手机界面或跨设备同步。默认资料位于「文档/终极日历本地版/数据」，备份位于同级「备份」目录。
- 本地版使用独立安装身份和 `local.yml` 更新通道，不读取标准版的云端连接配置，不自动迁移或覆盖标准版、云端资料。
- 标准版安装包 `UltimateCalendar-Setup-0.5.0.exe` 继续保留原有本地与云端连接方式，使用 `latest.yml`；两种版本的安装包和更新元数据分别校验。

## 桌面功能更新

- 生活助手支持添加或粘贴 PNG/JPEG 图片，发送前可预览和移除；视觉分析需所选模型支持。
- 外部 Agent 计划支持 v1 整目标新建、v2 增量追加和 v3 明确修订；可导出目标上下文或忙碌时间，导入前核对变更与冲突。
- 区分完成执行时段与完成整项任务，保留未完成任务的后续安排。
- 改善 QQ 正文与附件事项归并、教学文档练习归组、重复附件处理及原附件查看；减少将群内他人问答误提炼为自己的待办。
- README 以本地版下载与使用为主，手机和资料服务部署说明移至独立的自托管文档。

QQ 自动采集仍需用户自行配置本机 OneBot 兼容桥，安装包不包含 QQ 或桥接组件。提醒需要应用保持运行。仓库及安装包仅包含程序与合成测试资料，不包含私人课表、账目、消息或密钥。
