## 终极日历本地版 0.6.0

下载 `UltimateCalendar-Local-Setup-0.6.0.exe` 在 Windows x64 使用。日历、课表、任务、目标和账本保存在自己的电脑上，无需部署日历服务器；手动功能无需 API Key。AI 由本机调用自己的 DeepSeek API，需要联网并由自己的 API 账户承担费用。本地版只提供桌面端，没有手机端或跨设备同步。

### 微信群通知、图片与文件

- 新增「我的 → 微信采集」：连接本机微信后选择需要采集的群，独立启用采集。默认没有选群且未开启，不影响已有 QQ 设置。
- 只读采集电脑微信已同步的文本、卡片标题，以及已缓存、下载的图片和文件，交给现有附件解析与 AI 提炼流程；提炼结果先进入待判断列表，由用户决定是否采用。
- 未下载的附件明确提示并单独等待，临时缺失自动复查，不拖住其他消息；可在微信下载后重试或补采近期记录。保留已完成的分析检查点。
- **微信采集需要额外配置。** 安装包不包含微信客户端、Python 运行时及依赖，部分 HEVC 图片还需单独安装 FFmpeg。请先读[微信配置指南](https://github.com/Albert071006/ultimate-calendar/blob/v0.6.0/docs/wechat-capture.md)。它不会自动操作微信下载或发送消息，不读取完整微信云端历史；语音、视频和压缩包不做内容分析。兼容性取决于微信客户端版本，图片识别还需所选模型支持视觉输入。

### 安排与通知修复

- 普通任务默认只有一个执行时段，完成或恢复该时段时同步任务状态，减少重复点击「完成」。需要分次执行时，在任务或关联时段编辑中明确勾选「安排多个时段」。已有多段及重复安排保留。
- 同名通知中的「明天」按各自消息发送日期解析，避免跨日通知被误合并为同一事项。
- 已处理通知按列表显示时间从新到旧排列，便于找到最近事项。

### 升级与版本选择

本地版继续使用独立安装身份、`local.yml` 更新通道与「文档/终极日历本地版」资料目录；升级保留本地资料和有效凭据，不自动导入标准版或云端资料。QQ 自动采集仍需另行准备本机 OneBot 兼容桥。

需要手机和电脑共用资料的用户，请选择单独发布的[服务器版与手机端 0.6.0](https://github.com/Albert071006/ultimate-calendar/releases/tag/server-v0.6.0)。本地版与标准版更新通道保持分离。安装包尚未购买代码签名证书，请核对同一 Release 的 `SHA256SUMS-local.txt`。
