## 终极日历本地版 0.7.0

下载 `UltimateCalendar-Local-Setup-0.7.0.exe` 在 Windows x64 使用。日历、课表、任务、目标和账本保存在自己的电脑上，无需部署日历服务器；手动功能无需 API Key。AI 由本机直接调用自己的 DeepSeek API，需要联网并由自己的 API 账户承担费用。本地版只有桌面端，没有手机端或跨设备同步。

### 借入、借出与还收本金

- 新增「借入」「借出」「归还借款」「收回借款」四种记账类型，生活助手与手工记账均可使用。借入和收回记到账，借出和归还记付款；本金不计普通收入、资产变现或个人开销。
- 归还或收回可关联对应的原借款，支持分次、跨月结清。账单展示待还、待收及每笔本金、已还收和剩余金额，与原有 AA / 代垫待收回分开统计。
- 原借款未登记时，可记录本次真实收付并保留「未关联、剩余未知」，不会猜测抵扣另一笔借款。利息、手续费需单独记消费或收入。
- 保留「其他还款（信用卡等）」及原有记录，不自动把旧还款改成借款本金；本版仍不提供完整的信用卡负债管理。

### 独立银行与店铺账户

- 在「账单 → 账户」新增现金或储值账户，编辑账户名称和别名。同一家银行的多张卡可用尾号区分，不同店铺的会员卡可分别管理。
- 支付、转账、借款、筛选、明细、余额核对及固定生活费规则使用同一份账户目录。修改名称或别名保留账户身份、原流水和余额；不会自动把历史账目改归新账户。
- 生活助手可依据明确提供的银行、店铺名称建立独立账户；名称对应多张卡或信息不足时要求核对，不把明确账户随意记到泛称银行卡或另一家店铺。
- 新账户余额为未知。真实交易可照常记录，需用户提供余额快照后才能核对账面余额，不虚构初始金额。

### 生活助手错误与重试

现在分别提示响应为空、截断、JSON 无效或字段不符合约定，并给出不包含原始账目内容的诊断标识。确定模型结果未采用时，可主动选择「重新分析」；这会再次调用自己的 API。交易校验拒绝会显示具体原因；已保存或处理结果未知的请求先核对回执，不盲目重放，也不把已拒绝的原提案直接重新记入。

### 升级前请备份

0.7.0 新增的借款类型和自定义账户数据不受旧版支持。升级前备份，正常退出应用后再安装；开始使用新数据后，不要直接换回旧程序打开同一份资料。需要恢复时，应核对备份与程序的兼容性，保留升级后新增记录，不能靠清空资料解决。

本地版继续使用独立安装身份、`local.yml` 更新通道与「文档/终极日历本地版」资料目录，升级保留有效凭据，不自动导入标准版或云端资料。QQ、微信采集仍是需另行配置的可选功能，见[本地版指南](https://github.com/Albert071006/ultimate-calendar/blob/v0.7.0/docs/local-desktop.md)。安装包未购买代码签名证书，请核对同一 Release 的 `SHA256SUMS-local.txt`。

需要手机和电脑共用资料时，请选择单独发布的[服务器版与手机端 0.7.0](https://github.com/Albert071006/ultimate-calendar/releases/tag/server-v0.7.0)，并同时升级后端、Windows 标准版和手机页面。
