## 终极日历本地版 0.8.0

下载 `UltimateCalendar-Local-Setup-0.8.0.exe` 在 Windows x64 使用。日历、课表、任务、目标和账本保存在自己的电脑上，无需部署日历服务器；手动功能无需 API Key。AI 由本机直接调用自己的 DeepSeek API，需要联网并由自己的 API 账户承担费用。本地版只有桌面端，没有手机端或跨设备同步。

### 可调思考强度

在「我的 → AI 与费用」选择模型及思考强度后保存。`deepseek-flash`、`deepseek-v4-pro` 提供关闭、低、高、最高四档，默认关闭；其他模型保持原请求方式。较高强度可能增加等待时间和 token 用量，适合需要进一步理解的复杂指令。

开启思考的请求不会因超时或响应中断自动重发，避免重复调用。结果未知时先核对状态；已付费的采集检查点也不会仅因切换模型或强度重新调用。

### 通知理解与界面修复

- 处理「部分同学因另有课程可晚到」等到场补充时，要求关联可验证的原事项，保留适用对象、晚到条件和原活动时间；不把原因课程变成新活动，也不把局部例外改成全员时间。无法确认关联时进入校对。
- 对采集模型返回的明确、有效但缺少秒或时区的活动时间，按既定北京时间补齐格式；不猜测缺失的日期或时间，不改已完成的分析检查点。
- 修复接受活动后的长提示挤压日历工具栏、图例及右侧列表。切换主页面时清除过时成功提示，保留错误与撤销入口。
- 记账规则未保存的修改在本次运行中切换页面后仍保留，并明确提示保存状态。需要点击「保存记账规则」才会生效；关闭应用前请保存。
- 移除记账设置底部重复的只读口径与别名区域。账户名称、别名统一在「账单 → 账户 → 编辑账户」修改。

### 升级与下载核对

升级前备份并正常退出应用。保存新版思考设置后，旧程序可能无法读取同一份设置；之前版本的借款、自定义账户兼容限制也仍适用。回退前核对数据与目标版本兼容性，保留升级后的新增记录，不要通过清空资料解决升级问题。

本地版继续使用独立安装身份、`local.yml` 更新通道与「文档/终极日历本地版」资料目录，升级保留有效凭据，不自动导入标准版或云端资料。QQ、微信采集仍需另行配置，见[本地版指南](https://github.com/Albert071006/ultimate-calendar/blob/v0.8.0/docs/local-desktop.md)。安装包未购买代码签名证书，请核对同一 Release 的 `SHA256SUMS-local.txt`。

需要手机和电脑共用资料时，选择单独发布的[服务器版与手机端 0.8.0](https://github.com/Albert071006/ultimate-calendar/releases/tag/server-v0.8.0)，自行部署常在线服务器。
