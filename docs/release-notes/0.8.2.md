## 终极日历本地版 0.8.2

下载 `UltimateCalendar-Local-Setup-0.8.2.exe` 在 Windows x64 使用。日历、课表、任务、目标和账本保存在自己的电脑上，无需部署日历服务器；手动功能无需 API Key。AI 由本机直接调用自己的 DeepSeek API，需要联网并由自己的 API 账户承担费用。本地版只有桌面端，没有手机端或跨设备同步。

### 固定生活费自动检查

在「我的 → 记账」启用固定生活费并保存金额、起始月份和到账账户后，应用在启动、休眠恢复及运行期间每 30 秒空闲检查一次，按已经到来的月份生成记录，不必先打开账单。应用忙于其他操作时会稍后检查，不保证在每月 1 日 00:00:00 精确执行；关机或退出期间不运行，重新打开后检查应处理月份。

已有记录、已撤销或作废月份不会重复生成，暂停期间不补记，未来月份不提前记录。账户未指定时仍保留待确认，不擅自选择支付账户。该功能按用户保存的约定记账，不向支付平台核验真实到账。规则默认关闭，不随升级自动启用或修改已有配置。

### API 缓存与记账修复

- QQ、微信消息提炼的固定提示和结构不再混入每批变化的来源 ID；动态来源列表放在本次输入中，回答仍按当前允许来源严格校验，旧分析进度和已保存回答继续保留。
- 生活助手将稳定资料放在动态时间、页面、选择等信息之前，文字和图片请求使用一致的固定安全规则。最新账本、当前时间、对话角色和防重复校验仍完整保留。缓存改善需要观察升级后的正常调用，受服务商缓存状态和实际输入变化影响，不承诺固定命中率；历史统计不会改变。
- 修复原消费全额计入个人开销时的 AA 返款处理：只有原消费唯一且金额关系明确时，才在同一事务中更正个人承担并记录返款到账。返款不算普通收入；已按个人净额登记的原消费不会再次冲减，关系不明确或金额超出范围时仍需核对。
- 支持登记已用亲情卡归还的借款本金，手工录入和生活助手共用规则。本金减少待还、增加亲情卡已使用额，不重复计个人开销或收入，不扣微信、支付宝等现金余额，也不推算亲情卡真实剩余额度。利息和手续费另记，借入、借出及收回本金的账户限制保持。

### 升级与下载核对

升级前备份并正常退出应用，保留资料与有效凭据。**保存亲情卡归还借款记录后，旧版可能无法读取该账本；回退前必须核对目标程序是否支持这些记录，并保留升级后新增资料，不能直接恢复旧数据库覆盖。** 此前思考设置、自定义账户和采集检查点的兼容要求仍适用。

本地版继续使用独立安装身份、`local.yml` 更新通道与「文档/终极日历本地版」资料目录，不自动导入标准版或云端资料。QQ、微信采集需另行配置，见[本地版指南](https://github.com/Albert071006/ultimate-calendar/blob/v0.8.2/docs/local-desktop.md)。安装包未购买代码签名证书，请核对同一 Release 的 `SHA256SUMS-local.txt`。

需要手机和电脑共用资料时，选择单独发布的[服务器版与手机端 0.8.2](https://github.com/Albert071006/ultimate-calendar/releases/tag/server-v0.8.2)，自行部署常在线服务器。
