## 终极日历本地版 0.9.0

下载 `UltimateCalendar-Local-Setup-0.9.0.exe` 在 Windows x64 使用。日历、课表、任务、目标和账本保存在自己的电脑上，无需部署日历服务器；手动功能无需 API Key。AI 由本机直接调用自己的 DeepSeek API，需要联网并由自己的 API 账户承担费用。本地版只有桌面端，没有手机端或跨设备同步。

### 个人背景辅助判断通知

在「我的 → 学期与节次」填写可选的「个人身份与职责补充」，例如姓名、学号、班级、社团职务或负责事项，保存后供 QQ、微信消息提炼及生活助手使用。资料用于之后的新分析，不会自动重跑历史消息。没有填全身份时，不会把资料当作完整名单而直接排除其他通知；全体通知、明确提及本人或仍有疑问的事项保留判断空间。

群内后续通知可以结合此前已解析的附件文字，包括 Excel 的工作表和行位置。上下文仅取同群最近 24 小时内、最多 20 条候选消息中的至多 3 个附件，并受文字限额约束；复用本机解析缓存，不重新下载或付费重分析历史附件。名单本身不直接生成任务，也不成为永久的群过滤规则。学号、姓名与班级用于核对身份；同名冲突、附件缺失或读取不完整时，不据此认定名单没有本人。

### 生活助手多图与文件读取

- 支持一次选择或粘贴多张图片，并逐张移除；每次请求合计最多 4 张 PNG/JPEG 图片。图片理解仍取决于所选模型的视觉能力。
- 新增「读取文件」，可在本机提取 Excel、Word、PowerPoint、文本和文字 PDF 等内容，再随指令交给助手。旧版 DOC/PPT 需要本机具备相应转换能力。
- 文件先在本机解析，发送文件名与提取文字，不发送本机完整路径。使用 AI 时，所需文字或图片仍会发送给自己的 AI 服务商。
- 加密、损坏、超限或不能完整读取的文件会明确提示；扫描 PDF、需要视觉理解的页面请另提供图片。仅选择附件而未说明需求时，助手先询问用途，不直接记账。
- 修复快递费等交易被归入已有餐饮分类的问题：历史分类仅供参考，按本次交易用途选择或新增分类，并支持自定义；手动记账默认「其他」，升级不批量改动原账分类。

### 聊天历史与高度调整

修复生活助手内的滚轮翻看历史。拖动聊天框顶部即可调整高度，大小在本机记住，并随窗口可用空间调整。翻看旧消息时不强制跳回底部，收起再展开保留滚动位置。

### 升级与下载核对

升级前保存草稿、备份并正常退出应用，保留资料与有效凭据。写入新的个人资料、附件对话或采集检查点后，回退前须核对目标版本是否支持这些内容，并保留升级后新增资料，不能直接恢复旧数据库覆盖。此前账本、思考设置及自定义账户的兼容要求仍适用。

本地版继续使用独立安装身份、`local.yml` 更新通道与「文档/终极日历本地版」资料目录，不自动导入标准版或云端资料。QQ、微信采集需另行配置，见[本地版指南](https://github.com/Albert071006/ultimate-calendar/blob/v0.9.0/docs/local-desktop.md)。安装包未购买代码签名证书，请核对同一 Release 的 `SHA256SUMS-local.txt`。

需要手机和电脑共用资料时，选择单独发布的[服务器版与手机端 0.9.0](https://github.com/Albert071006/ultimate-calendar/releases/tag/server-v0.9.0)，自行部署常在线服务器。
