## 终极日历本地版 0.9.2

下载 `UltimateCalendar-Local-Setup-0.9.2.exe`，适用于 Windows x64。日历、课表、任务和账本保存在自己的电脑上，无需部署服务器；AI 由本机调用自己的 DeepSeek API。本地版只有桌面端，没有手机端或跨设备同步。

### 本次修复

批量记账遇到同月或同日的同额记录时，明确提示整批尚未保存，并保留本次清单和重复确认问题。回复“是”会承接最近的记账澄清，不再因为错误消息丢失而跳回更早的撤销对话；已保存或结果未知的操作仍保留原有防重复保护。日期待确认时提示相同月份，不把整月当成同一天。

生活助手输入框随多行或自动折行的内容增高，最多显示约六行；更长的内容可以在输入框内上下滚动，清空后恢复紧凑高度。保留 Enter 发送、Shift+Enter 换行。

“记一笔”继续保持手动录入，分类可自行选择或直接填写新名称；本次没有添加手动录入自动分类，也不重分类已有账目。

### 升级

保存未发送草稿并正常退出后安装，保留已有资料和 API Key。继续使用独立安装身份、资料目录及 `local.yml` 更新通道。可用同一 Release 的 `SHA256SUMS-local.txt` 核对安装包；安装包未购买代码签名证书。

需要电脑和手机共用资料时，使用单独发布的[服务器版与手机端 0.9.2](https://github.com/Albert071006/ultimate-calendar/releases/tag/server-v0.9.2)，并自行部署常在线服务器。
