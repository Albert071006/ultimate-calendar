# 服务器版与手机端 0.10.1

需自行维护 Node.js 24 服务器、域名和 HTTPS。Windows 标准版与手机共用同一资料服务。

本版修复生活助手的账本查询和多轮追问：按单笔项目、备注或明确记录筛选，避免整批原文混入无关消费；查询显示实际范围，短答承接已给出的选项，多轮补充保留原需求及账户依据。明确的全额报销按各笔剩余开销冲减，支持跨分类、跨月份；分配不明时正常澄清，不保存半批账目。实际到账、额外收入和原费用冲减分别核算，保留幂等、版本检查及整批撤销。

电脑和手机的手动分类选择可直接展开全部选项，并保留自定义输入。Windows 标准版还包含微信临时账号未就绪的重试修复，保留绑定和群选择；账号明确改变或身份不明时仍保留隔离保护。

## 下载与更新

- `UltimateCalendar-Setup-0.10.1.exe`：Windows 标准客户端及同次构建的更新元数据、blockmap、校验表。
- `UltimateCalendar-Server-Mobile-0.10.1.tar.gz`：后端、备份 worker、手机网页/PWA、部署配置与文档。
- `SHA256SUMS-server.txt`：部署包校验表。

协调更新后端、手机资源和 Windows 客户端。正常停止服务后切换代码，保留正式资料、环境配置和配对；完整部署 `cli.mjs` 与同次构建的 `backup-worker.cjs`，保留旧页面引用的指纹资源。手机重新打开即可获取新版，不要求清空缓存或重新配对。

旧客户端接收兼容响应；新版客户端才能完整保留查询选项和使用新的分类控件。账本数据格式不变，但操作回执可能包含新的查询字段及选项，回退旧后端前必须检查这些回执及既有数据兼容性，不恢复旧数据库覆盖新资料。

升级不补记历史失败请求、不重跑已完成分析、不修改原分类。发布包不代表自动替使用者部署。无需云服务时请使用[纯本地版 0.10.1](https://github.com/Albert071006/ultimate-calendar/releases/tag/v0.10.1)。
