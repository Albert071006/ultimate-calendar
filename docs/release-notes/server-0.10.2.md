# 服务器版与手机端 0.10.2

本版修复群通知遗漏、时间范围丢失和冲突预览，并改善 Windows 客户端与手机的生活助手、账单和日历使用体验。需要自行维护 Node.js 24 服务器、域名和 HTTPS。

- 群通知可使用腾讯文档、小程序卡片的可见内容及后续资格、名额补充。限定人群通知补充判断例子，在本人是否符合条件不明时保留适用对象待核对。
- 支持带空格的中文钟点和单字时段词；同一活动的结束钟点可沿用已核对的开始日期，避免把明确的 90 分钟活动缩为默认 30 分钟。接受通知与导出忙碌时间使用同一完整范围；不借用另一个活动或次日的钟点。
- 修复课程自身考核的误报，以及冲突详情指向新活动自己的问题。通知接受预览优先显示日历安排，导入计划核对使用易读日期，内部变更细节折叠。
- 电脑和手机助手支持常用 Markdown、中文日期和简洁记账汇总，去除重复保存提示；日程附表默认折叠，长回复从开头显示，保留用户翻看旧消息的位置及后续对日程的指代。
- Windows 日历活动标题、截止条和单日提示更清楚，长提示独立显示，不挤动工具栏。电脑和手机的固定活动结束后用中性状态，不自动标记完成，执行时段仍保留待处理提醒。账单汇总全部月份的代垫与借出待收款，借款显示金额和剩余本金，未设置余额的说明更明确。

## 下载与更新

- `UltimateCalendar-Setup-0.10.2.exe`：Windows 标准客户端，附同次构建的更新元数据、blockmap 和校验表。
- `UltimateCalendar-Server-Mobile-0.10.2.tar.gz`：后端、备份 worker、手机网页/PWA、部署配置及文档。
- `SHA256SUMS-server.txt`：部署包校验表。

协调更新后端、手机页面与 Windows 采集客户端；完整部署 `cli.mjs` 和同次构建的 `backup-worker.cjs`，保留旧页面引用的指纹资源、现有资料、密钥和配对。发布包不会自动替使用者部署。

本次不迁移账本格式、不批量修改旧活动、不重跑历史分析或改变已处理通知的决定。旧卡片只有在仍保存可核对原文与时间证据时才能恢复时间；未保留原文的云端历史记录不凭描述猜补。新的卡片解析检查点需由支持它的采集端读取，降级前核对检查点及既有回执，不恢复旧数据库覆盖新资料。

无需服务器时请使用[纯本地版 0.10.2](https://github.com/Albert071006/ultimate-calendar/releases/tag/v0.10.2)。
