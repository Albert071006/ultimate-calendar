# 服务器版与手机端 0.10.3

本版完成全项目系统性审计修复，重点加固过期设备推送隔离、安全备份脱敏、云端恢复与大体积更新前备份，并同步升级 Windows 标准版、后端服务与手机网页的记账、采集和性能体验。需要自行维护 Node.js 24 服务器、域名和 HTTPS。

- 安全与隐私边界：设备会话过期后在推送排队与发送前均被拦截，不再向旧浏览器发送提醒正文；截图导入不再夹带隐藏文字草稿并区分本机/云端保存提示；服务端自动安全备份与下载导出共用递归脱敏逻辑，清除账目及审计内嵌账目中的原文；清理采集原文同步擦除日历来源副本。
- 账本、助手与手机体验：生活助手保存前核对原话金额、支持更正原笔金额语序与付款账户逐笔校验，禁止模型自填跳过重复账确认；手工编辑器保留多账户分摊与报销关联，只改备注不再改坏待收款；拆清图片追问写入意图与历史收据证据；手机离线改账冲突重提时先刷新目标月份最新账本；手机日视图整周复用日历构建结果。
- 采集、恢复与会话可靠：活跃桌面、采集端与摘要桥会话自动续期并区分设备授权错误；在线恢复保留摘要通知的修订与三方合并基线，恢复后旧通知仍可正常接收补充；外部计划导入回执按服务实例、恢复代际与设备分区，不再被旧未明计划卡死；离线恢复兼容空颜色旧备份；QQ 附件警告按来源归属隔离不再连坐同批纯文字通知；微信补齐延迟同步巡检、100+ 超长 @ 名单完整扫描、3 天自动重试上限、追加独立作业分离与超时临时目录清理。
- 大备份、性能与部署：桌面端导出和更新前云端安全备份改为 1 MiB 分块下载与哈希回读校验，支持至 64 MiB；账本新操作日志和云端回执改为向后兼容的可逆差量与精简回执，大幅缩减增长体积且兼容撤销旧记录；统一后端部署包 `backup-worker.cjs` 显式清单，双版本 Release 归档原字节支持安全续发；补充 Windows QQ 采集 LLBot 安装指南。

## 下载与更新

- `UltimateCalendar-Setup-0.10.3.exe`：Windows 标准客户端，附同次构建的更新元数据、blockmap 和校验表。
- `UltimateCalendar-Server-Mobile-0.10.3.tar.gz`：后端、备份 worker、手机网页/PWA、部署配置及文档。
- `SHA256SUMS-server.txt`：部署包校验表。

协调更新后端、手机页面与 Windows 采集客户端；完整部署 `cli.mjs` 和同次构建的 `backup-worker.cjs`，保留旧页面引用的指纹资源、现有资料、密钥和配对。发布包不会自动替使用者部署。

升级保留既有资料、配对与已处理通知决定，不自动重跑历史分析或批量改写旧活动。新版写入的差量账本操作日志、精简云回执、独立摘要基线及新采集游标需由支持它们的程序读取，降级前请先核对兼容性，不以恢复旧数据库代替程序回退。

无需服务器时请使用[纯本地版 0.10.3](https://github.com/Albert071006/ultimate-calendar/releases/tag/v0.10.3)。
