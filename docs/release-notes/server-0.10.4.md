# 服务器版与手机端 0.10.4

本版统一了 Windows 客户端和手机网页的账单更正、保存提示与撤销体验。部署需要自行维护 Node.js 24 服务器、域名和 HTTPS。

- 在电脑或手机上手工更正账单时，都可省去填写「更正说明」的步骤。「修改记录」按字段列出金额、账户、分项收付和关联原消费等内容的新旧值。只改备注时记为「修改备注」，原样保存时记为「手工核对保存」。作废说明选填，留空记为「手工移除」。生活助手提交的修改理由仍可在记录中查看。
- 两端统一在页面底部显示操作提示，约 4 秒后淡出。手机账单的新增、更正、作废、余额核对、撤销和导出均有反馈。提示中的「撤销」对应刚完成的日程或账单操作，离线暂存的账单会提示等待同步。电脑端悬停提示或将键盘焦点移到「撤销」按钮可暂停计时，错误提示会保留至关闭或问题解决。
- Windows 日历可在工具栏或日期表头滚轮翻页，也可在日历主体按住 Shift 滚动或横向滑动。日、周时间轴保留上下滚动。月视图一屏可见时可直接滚轮翻月，超出窗口高度时优先滚动内容，同一次滑动只翻一页。
- 电脑和手机各自记住上次选用的日历视图。例如，电脑可以一直用周视图，手机可以一直用「3天」视图。从月视图点开某天也会记住日视图。再次打开时，电脑从「日历」、手机从「今天」开始，日期仍回到今天。

## 下载与更新

- `UltimateCalendar-Setup-0.10.4.exe` 为 Windows 标准客户端安装包，同次构建的更新元数据、blockmap 和校验表随包发布。
- `UltimateCalendar-Server-Mobile-0.10.4.tar.gz` 包含后端、备份 worker、手机网页/PWA、部署配置及文档。
- `SHA256SUMS-server.txt` 用于校验服务器与手机端部署包。

请协调更新后端、手机页面与 Windows 客户端。部署时使用同一归档中的 `cli.mjs` 和 `backup-worker.cjs`，保留旧页面引用的指纹资源、现有资料、密钥和设备配对。

只在电脑本机使用时，可下载[纯本地版 0.10.4](https://github.com/Albert071006/ultimate-calendar/releases/tag/v0.10.4)。
