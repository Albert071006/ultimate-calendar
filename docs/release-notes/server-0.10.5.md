# 服务器版与手机端 0.10.5

本版让 Windows 客户端和手机网页共用一份专注历史。计时器在发起设备走时，保存后，独立的专注记录通过服务器增量同步到两端。部署需要自行维护 Node.js 24 服务器、域名和 HTTPS。

- 电脑和手机都可从「今天」、任务或执行时段启动番茄倒计时或正向计时。两端保留五项主导航，切页后可以从迷你计时条继续操作。手机计时条位于底部导航上方。
- 刷新、锁屏或重启后，原设备按实际经过时间恢复计时并扣除暂停。离开期间番茄已到点时按原目标时长等待保存。有效专注满 1 分钟即可记录，休息由你选择开始。在「番茄钟与专注」可调整专注、短休和长休时长、长休间隔及提示音。
- 「今日专注」汇总当天时长和完成番茄数。「我的 → 专注统计」按北京时间展示日、周、月时间账单，可查看每日投入、按课程或目标筛选明细，也能手动补录、编辑、删除和撤销记录。
- 两端的生活助手都能查投入、补录明确的单条记录。修改或删除历史记录先预览，匹配多条时先追问。可以让助手在当前设备启动、暂停、继续或结束计时。遇到已有计时时会弹出切换选择，重试请求或恢复手机聊天历史不会重复启动。
- Windows 日历在页面布局时绑定滚轮监听，改善刚打开日历时的首次翻页。

## 下载与更新

- `UltimateCalendar-Setup-0.10.5.exe` 为 Windows 标准客户端安装包，更新元数据、blockmap 和校验表随同一次构建提供。
- `UltimateCalendar-Server-Mobile-0.10.5.tar.gz` 包含后端、备份 worker、手机网页/PWA、部署配置及文档。
- `SHA256SUMS-server.txt` 用于校验服务器与手机端部署包。

请协调更新后端、手机网页和 Windows 客户端，使用同一归档中的 `cli.mjs` 和 `backup-worker.cjs`，保留现有资料、密钥、设备配对和旧页面引用的指纹资源。新版服务首次打开旧数据库时会自动创建 `focus_sessions` 表并补入默认专注设置。旧备份缺少这些字段也可正常恢复，已有日程和账目保留，专注历史从空列表开始。

只在电脑本机使用时，可下载[纯本地版 0.10.5](https://github.com/Albert071006/ultimate-calendar/releases/tag/v0.10.5)。
