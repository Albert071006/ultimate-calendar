## 服务器版与手机端 0.8.0

本 Release 供手机与 Windows 电脑共用一份日历、任务和账本。使用者需要自行部署并维护一台常在线的 Linux 云服务器，配置 Node.js 24、域名与 HTTPS。服务器保存资料并调用自己的 DeepSeek API，手机通过网页/PWA 使用，Windows 标准版可连接同一服务。项目不提供公共托管账号。

### 下载内容

- `UltimateCalendar-Server-Mobile-0.8.0.tar.gz`：已构建的 Node 后端、手机网页/PWA、systemd 配置、NGINX 示例和部署说明，目标服务器无需运行 `npm ci`。
- `SHA256SUMS-server.txt`：服务器部署包校验文件。
- `UltimateCalendar-Setup-0.8.0.exe`：可选 Windows 标准版客户端，另附同次构建的更新元数据、blockmap 和校验文件。

首次部署见[Linux 部署与手机使用指南](https://github.com/Albert071006/ultimate-calendar/blob/server-v0.8.0/docs/server-mobile-deployment.md)。每台设备用服务器生成的一次性码配对；没有 API Key 时仍可手动管理资料。服务器在线时，Windows 电脑关机不影响手机读写，但新的本机 QQ、微信采集会暂停。

### 本次更新

- **共享思考强度**：电脑「我的 → AI 与费用」和手机「我的 → 生活助手」均可选择模型及思考强度，保存后共用。`deepseek-flash`、`deepseek-v4-pro` 提供关闭、低、高、最高四档，默认关闭；其他模型保持原请求方式。较高强度可能增加等待时间和 token 用量，采集端也会同步模型与强度。
- **保存与请求保护**：防止旧设置表单覆盖另一端已保存的思考强度。开启思考的请求遇到超时或响应中断不自动重发，设置保存结果未知时先核对；已付费的采集检查点不会仅因改变模型设置重新调用。
- **记账设置**：未保存草稿在本次运行中切页后仍保留，明确显示保存状态；仍需点击保存生效，离线排队不冒充成功。移除重复只读说明，账户名称及别名统一在「账单 → 账户 → 编辑账户」修改。
- **桌面日历布局**：修复长成功提示挤压工具栏、图例与侧栏；切换主页面清除过时成功消息，保留错误与撤销入口。
- **本机通知提炼**：到场补充须关联可验证的原事项，保留局部适用对象和原活动时间，避免把晚到原因识别为新活动；关联不明时要求校对。明确且有效的本地活动时间可按既定北京时间补齐秒和时区，避免仅因格式缺失拒绝结果。

QQ、微信采集仍在 Windows 电脑运行，手机和 Linux 服务端不直接登录 QQ 或微信，见[微信配置指南](https://github.com/Albert071006/ultimate-calendar/blob/server-v0.8.0/docs/wechat-capture.md)。本版不会自动重写历史通知、账目或备份。

### 协调升级并保留资料

升级前备份服务器资料并校验部署包，正常停止服务后更新后端与手机静态资源，同时更新 Windows 标准版至 0.8.0。保留数据、凭据、设备配对和环境配置，手机关闭旧页面后重新打开或刷新，无需清空资料或重新填写有效 Key。

**保存新版思考设置后，旧后端或旧桌面程序可能无法读取这些设置。** 之前版本的借款和自定义账户兼容限制仍适用，回退前必须确认存储数据与目标版本兼容，并保护升级后的新增记录。旧客户端可以保持已有思考配置，但无法调整新选项；请协调升级各端。

手机静态部署须保留旧页面引用的指纹资源，避免缓存页面请求旧脚本时遇到 404，见[升级步骤](https://github.com/Albert071006/ultimate-calendar/blob/server-v0.8.0/docs/server-mobile-deployment.md#7-备份升级与恢复)。反向代理的 AI 请求等待时间也需覆盖较长的思考请求，并保持关闭写请求重试；详见部署指南。保留静态资源只保证页面能加载，不替代存储格式兼容检查。

本 Release 与[纯本地桌面版 0.8.0](https://github.com/Albert071006/ultimate-calendar/releases/tag/v0.8.0) 分开发布。本地版无需日历服务器，由电脑直连自己的 API，且没有手机端。两种桌面版继续使用独立安装身份、资料目录和更新通道。发布构建不代表已替使用者部署并验收其服务器或手机。
