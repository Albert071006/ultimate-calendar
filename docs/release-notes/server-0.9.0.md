## 服务器版与手机端 0.9.0

本 Release 供手机与 Windows 电脑共用一份日历、任务和账本。使用者需要自行部署并维护一台常在线的 Linux 云服务器，配置 Node.js 24、域名与 HTTPS。服务器保存资料并调用自己的 DeepSeek API，手机通过网页/PWA 使用，Windows 标准版可连接同一服务。项目不提供公共托管账号。

### 下载内容

- `UltimateCalendar-Server-Mobile-0.9.0.tar.gz`：已构建的 Node 后端、手机网页/PWA、systemd 配置、NGINX 示例和部署说明，目标服务器无需运行 `npm ci`。
- `SHA256SUMS-server.txt`：服务器部署包校验文件。
- `UltimateCalendar-Setup-0.9.0.exe`：可选 Windows 标准版客户端，另附同次构建的更新元数据、blockmap 和校验文件。

首次部署见[Linux 部署与手机使用指南](https://github.com/Albert071006/ultimate-calendar/blob/server-v0.9.0/docs/server-mobile-deployment.md)。每台设备用服务器生成的一次性码配对；没有 API Key 时仍可手动管理资料。服务器在线时，Windows 电脑关机不影响手机读写，但新的本机 QQ、微信采集会暂停。

### 本次更新

- **个人背景辅助判断**：在「我的 → 学期与节次」填写可选的个人身份与职责，帮助判断通知与自己的关系。保存的资料供生活助手使用，并同步给 Windows QQ、微信采集端；修改用于之后的新分析，不自动重跑历史消息。旧客户端保存设置时会保留新版的个人资料字段。
- **近期名单与后续通知关联**：群内后续通知可结合本机已解析的附件文字及表格行位置。范围限同群最近 24 小时、最多 20 条候选消息中的至多 3 个附件，并受文字限额约束。复用缓存，不重新下载或付费重分析历史附件；名单本身不直接生成任务，不成为永久过滤规则。同名冲突、身份不完整或附件读取不全时保留不确定性，不直接判定与本人无关。
- **生活助手多图**：电脑和手机均可选择或粘贴多张图片、逐张移除，每次请求合计最多 4 张 PNG/JPEG；所选模型需支持视觉输入。
- **桌面文件读取**：Windows 生活助手新增「读取文件」，在本机解析 Excel、Word、PowerPoint、文本及文字 PDF 等文件，将文件名与提取文字随请求发送给自己的服务器及 AI 服务商，不发送本机完整路径。手机暂不支持直接选择文档。加密、损坏、超限或读取不完整会提示；扫描 PDF 和需要视觉判断的页面请另提供图片，旧 DOC/PPT 需相应转换能力。
- **桌面聊天框改进**：修复滚轮翻历史，支持拖动顶部调整高度并在本机记住大小；翻看旧消息不强制跳回底部，收起再展开保留滚动位置。
- **记账分类修复**：修复生活助手把快递费等交易归入已有餐饮分类的问题。历史分类仅供参考，按本次交易用途选择或新增分类，并支持自定义；手动记账默认「其他」，升级不批量改动原账分类。

QQ、微信采集及原文附件仍在 Windows 电脑上，手机和 Linux 服务端不直接登录 QQ 或微信。个人资料用于辅助模型判断，不保证每条通知都能准确匹配；明确提及本人、全体通知或仍需确认的事项不因资料未填全而被直接排除。

### 升级并保留资料

升级前备份并校验部署包。按部署指南更新服务器包和手机静态资源，正常退出后更新 Windows 标准版至 0.9.0；保留资料、凭据、设备配对和环境配置。手机完整关闭旧页面再打开，以启用新版页面，无需清空资料或重填有效 Key。多附件请求及个人资料保存需要新版后端，群附件关联需要新版 Windows 采集程序。发布下载包不代表已经替使用者部署服务器。

**写入个人资料、多附件对话或新采集检查点后，回退前必须检查目标后端和桌面程序能否读取这些内容。** 保留升级后新增资料，不能用旧数据库覆盖；旧页面兼容不代表旧后端可以安全回退。此前亲情卡归还借款、思考设置及自定义账户的兼容要求仍适用。手机静态部署须保留旧页面引用的指纹资源，见[升级步骤](https://github.com/Albert071006/ultimate-calendar/blob/server-v0.9.0/docs/server-mobile-deployment.md#7-备份升级与恢复)；恢复或替换本机采集数据库前，还应正常停止持有只读连接的摘要发送桥。

本 Release 与[纯本地桌面版 0.9.0](https://github.com/Albert071006/ultimate-calendar/releases/tag/v0.9.0)分开发布。本地版无需日历服务器，由电脑直连自己的 API，没有手机端。两种桌面版继续使用独立安装身份、资料目录和更新通道。
