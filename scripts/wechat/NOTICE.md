# 微信只读适配器

`vendor/db.py` 来自 [fanyuantaier/wechatauto-replica](https://github.com/fanyuantaier/wechatauto-replica)，固定提交 `6e603974bbac3bda93d88bbd6995510ae2547f5c`（1.2.8.1），原文件未修改，Apache-2.0，许可证见 `vendor/LICENSE`。

日历仅加载这个数据库模块，不导入上游包入口、UI 自动化、发送或监听线程。`worker.py` 是日历自有适配：限制只读请求、账号绑定、分页、错误输出、私有临时目录；禁用上游密钥落盘、账号自动切换与额外数据库主密钥扫描。数据库密钥仅存于采集进程内存；解密副本位于本机私有缓存，正常退出删除。

`local_media.py` 的微信本机图片容器格式、图片密钥派生及内存读取思路改编自同一提交的 `wechatauto/media.py`（Apache-2.0），保留 Apache-2.0 授权；该文件是日历针对只读附件采集重写的受限子集，不加载上游媒体模块。它只读取已绑定群的原消息及本机已下载附件，核对消息身份、分片、类型、文件大小与可用 MD5，不将消息里的任意路径或 URL 当作文件来源。解码副本仅写入受限缓存；拒绝路径穿越、链接、同名歧义和超过 25 MiB 的附件。

图片优先取本机原图或压缩图，只有缩略图时提示在微信下载后重试；图片密钥只在内存中使用。需要时只读扫描微信进程，单次扫描限时 12 秒、累计候选内存 512 MiB，失败后至少等待 60 秒再扫描。扫描不修改微信进程，不触发界面操作。`wxgf`/HEVC 图片使用 Python 运行时目录下单独安装的 `ffmpeg.exe` 解码；仅允许管道输入输出，设有超时、内存分配、尺寸和附件大小限制。FFmpeg 不随此源码复制，安装时需保留对应构建的许可证。

运行依赖：64 位 Windows Python（已测 3.12 / 3.14）、`cryptography==50.0.2`、`zstandard==0.25.0`。微信数据库结构可能随客户端更新变化。支持文本、卡片标题、已下载的图片和文件；不驱动微信下载缺失附件，语音与视频仍需手动查看。图片与文件读取后交给日历已有识别流程，识别模型的支持范围与费用沿用用户配置。仅本机已同步的消息可读取，不能把本地历史读尽当作完整微信云端历史。
